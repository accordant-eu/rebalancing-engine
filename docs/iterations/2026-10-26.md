# Iteration Log: 2026-10-26 - Sandbox Fixes & Full Walkthrough Verification

## 1. Context & Problem Statement
During autonomous browser verification of the solution walkthrough ([docs/guides/solution-demo-walkthrough.md](../guides/solution-demo-walkthrough.md)), two key issues were identified on the Interactive Sandbox modal:
1. **Target Label Duplication**: Both target rows displayed `Microsoft (MSFT) 0,5 %` because the conditional check `t.instrumentId.includes('AAPL')` failed to match the composite ISIN `US0378331005:XNAS:USD`. Furthermore, weights displayed raw decimals (`0.5 %`) rather than whole percentages (`50 %`).
2. **Negative Cash Error on Simulation**: The simulation threw `Post-trade simulation produced negative cash` and background accounts encountered `Simulated cash does not reconcile with proposal estimated post-trade cash`. This was traced to runaway price oscillations in `ticker.ts` and legacy unhashed credentials preventing clean superadmin traversal.

## 2. Root Cause Analysis & Implementations
- **Asset Metadata & Label Resolution**:
  - Implemented `INSTRUMENT_METADATA` and `formatInstrumentLabel()` in [web/src/components/MarketingSandboxModal.tsx](../../web/src/components/MarketingSandboxModal.tsx) to map `US0378331005:XNAS:USD` -> `Apple Inc. (AAPL)` and `US5949181045:XNAS:USD` -> `Microsoft Corp. (MSFT)`.
  - Added clean stock name and ticker badges to Initial Holdings.
  - Formatted Target Allocation to display intuitive percentage integers (`50 %`) with bi-directional parsing supporting both percentage entries (e.g. `50`) and decimals (`0.50`).
- **Numerical Safeguards & Bounded Prices**:
  - In [src/simulator/ticker.ts](../../src/simulator/ticker.ts), added finite checks and bounded price oscillation limits (`Math.max(50, Math.min(500, ...))`) to prevent price drift from exploding.
  - In [src/api/server.ts](../../src/api/server.ts), sanitized `/api/public/sandbox/simulate` input prices, defaulting missing or non-finite prices to realistic values.
  - In [src/db/sqlite.ts](../../src/db/sqlite.ts), added baseline `GlobalPrices` seeding and auto-upgrading for legacy plaintext passwords to bcrypt hashes.
- **Test Suite Updates**:
  - Added `DELETE FROM GlobalPrices;` to [tests/ticker.test.ts](../../tests/ticker.test.ts) cleanup to guarantee isolated price state across tests.

## 5. Walkthrough UX Enhancements & Validation (Iteration 119)
Following end-to-end walkthrough verification, key UX friction points were eliminated across two scoped increments:
1. **Metrics Polish & Actionability**:
   - Implemented `formatCompactCurrency(value: number): string` to prevent massive aggregate AUM numbers (e.g. `$70,049,448,488.50`) from overflowing the Fleet HUD card and truncating, rendering clean formatted magnitudes (e.g. `$70.05B`, `$1.50T`, `$25.40M`) while preserving the exact decimal precision in the hover `title` tooltip.
   - Added an advisor `Batch Rebalance ({criticalDrift.length})` action directly on the *Action Required: Breached Drift* queue header, enqueuing all breached portfolios into the SQLite `EvaluationQueue` in parallel.
